Aplicação de Console para Gerenciamento de Cadastros em Python
Este projeto é uma aplicação de console desenvolvida para praticar e aplicar conceitos fundamentais da linguagem Python. O objetivo foi construir um sistema simples, porém completo, para o gerenciamento de usuários, manipulando dados armazenados em memória.

Funcionalidades Principais:
Cadastro de Usuários: Permite a criação de novos usuários com nome, e-mail e idade. Inclui tratamento de exceções para garantir que a idade seja um número inteiro válido.

Listagem Completa: Exibe no console uma lista formatada de todos os usuários cadastrados.

Busca por Nome: Permite a busca de um usuário específico pelo nome (case-insensitive), exibindo seus dados detalhados se encontrado.

Menu Interativo: Interface de console intuitiva que guia o usuário através das opções disponíveis.

Conceitos de Python Aplicados:
Este projeto serviu como um exercício prático para os seguintes conceitos:

Estruturas de Dados: Uso de listas para armazenar os usuários e dicionários para representar cada usuário.

Funções: Modularização do código em funções específicas para cada tarefa (menu, cadastrar, listar, buscar).

Controle de Fluxo: Utilização de laços while e condicionais if/elif/else.

Tratamento de Exceções: Implementação de blocos try-except para validar a entrada de dados do usuário.

Manipulação de Strings: Uso de métodos como .lower() para criar buscas não sensíveis a maiúsculas/minúsculas.

Como Usar:
Clone o repositório.

Navegue até a pasta do projeto pelo terminal.

Execute o comando: python nome_do_arquivo.py

Siga as instruções apresentadas no menu do console.
